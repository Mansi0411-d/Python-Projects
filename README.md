# Python-Projects
Beginner Python apps demonstrating coding skills in file handling, logic, and user interaction. Includes QR code generator for payment apps, Student Manager, Rent calculator, Rock-Paper-Scissor game, Photo Slideshow, Task Manager.
---

## 📌 Projects

### 1. Task Manager
A simple Python application to manage daily tasks.

**Features**
- Add new tasks
- Update existing tasks
- Delete tasks
- View all tasks in a list

**Skills Demonstrated**
- File handling
- Loops and conditionals
- User input handling
- Basic CRUD operations

---
### 2. Payment QR Generator
A Python script that generates QR codes for payment apps.

**Features**
- Generate QR codes for payment links or UPI IDs
- Save QR codes as image files
- Easy to share and scan

**Skills Demonstrated**
- Python libraries (`qrcode`)
- File handling
- Practical utility scripting

**Features**
- Add new student details
- Update existing records

- Display all students

**Skills Demonstrated**
- Data structures (lists/dictionaries)

### 4. Rent Calculator
A program to split rent fairly among roommates.

**Features**

**Skills Demonstrated**
- Arithmetic operations
- Logic building
- User interaction

### 5. Rock-Paper-Scissors Game
Classic game built with Python.

**Features**

### . Photo Slideshow
A Python application to display images in a slideshow format.

**Features**
- Load multiple images from a folder
- Display each image for a set duration
- Stop slideshow with a key press
- Resize images for consistent viewing

**Skills Demonstrated**
